## 这是什么

**YuCode** 是一个本地优先的 AI 工作台，专门为渗透测试和安全研究场景做了加强。

它继承自 [ZCode](https://github.com/zai-org/ZCode) 的多智能体协作能力（多供应商模型、Agent 会话、
工具调用、MCP 扩展），并在其上增加了一整套**渗透测试作战台**：资产、漏洞、调度、流程全部落盘即入库。

## 下载

前往 **[Releases](../../releases/latest)** 下载最新安装包：

| 文件 | 说明 |
| --- | --- |
| `YuCode-1.0.0-win-x64.exe` | Windows 64 位安装包（约 163 MB） |
| `latest.yml` | 自动更新清单（升级必需） |
| `YuCode-1.0.0-win-x64.exe.blockmap` | 差分更新索引（升级必需） |

> 三个文件**下载后放在同一个目录**，双击 exe 安装即可。
> 装完在首屏可以改选「独立使用 / 与 ZCode 共生」，两个模式功能完全一致。

## 快速开始

```
1. 安装          双击 exe，一路下一步
2. 选择运行模式  独立使用 / 与 ZCode 共生（选错的可以随时改）
3. 连接模型      登录账号，或填自己的 API Key
4. 激活          首屏「机器码注册」卡：复制机器码 → 换取激活码 → 粘贴激活
5. 开干          侧栏打开「渗透工作台」，把报告目录指过去
```

详细步骤见 [使用教程](docs/使用教程.md)。

## 授权

本产品采用**机器码绑定授权**：一份授权码对应一台电脑。

- 首屏复制机器码 → 发送给作者 → 获得一串激活码 → 粘贴即激活
- 激活**立即生效，无需重启**
- 未激活也能正常连模型、正常使用基础功能；激活解锁的是内置技能资产与商业功能

详见 [激活与授权](docs/激活与授权.md)。
