# 常见问题

---

## 安装与启动

**Q：安装包下不动 / 一直转圈？**
安装包 163 MB，走内网宽带正常。断点续传的话重新下载即可。

**Q：装完双击没反应？**
- 先确认系统是 Windows 64 位（右键「此电脑」看系统类型）
- 检查 Windows Defender 有没有拦截（偶尔会误报 Electron 应用）
- 右键以管理员身份运行一次试试

**Q：为什么文件名带 "Standalone"，我不想跟 ZCode 共存？**
Standalone 指**出厂默认独立使用**，不是功能阉割。装完在首屏可以改选
「与 ZCode 共生」，两个模式功能完全一致。想切回去：设置 ▸ 数据与模式。

**Q：能同时装官方 ZCode 吗？**
能，两者的应用 ID 不同，Windows 不会把它们互相覆盖。
但如果用「与 ZCode 共生」模式，**别同时开着两个**——它们共用同一个数据库，会互斥锁，
后启动的会等锁。关掉一个再开另一个即可。

## 授权

**Q：一定要激活吗？**
基础功能不需要。激活解锁的是内置技能资产和后续商业功能。
详见 [激活与授权](激活与授权.md)。

**Q：换电脑了怎么办？**
机器码会变，需要重新申请一份授权。

**Q：激活码会被人盗用吗？**
授权码**绑定机器码**，别人拿到也用不了（会提示"授权不匹配本机"）。
但反过来也一样——如果别人同时拿到你的机器码和你机器上的授权文件，那拦不住。
所以别把授权文件随便发人。

## 数据与隐私

**Q：我的数据在哪？卸载会丢吗？**
独立模式在 `~/.ycode`，共生模式在 `~/.zcode`——都是你 HOME 下的普通文件。
**卸载应用不删数据**，重装后还在。

**Q：会上传我的东西吗？**
不会。资产、漏洞、报告、对话、记忆全部本地存储。
只有你主动调用云端模型时，提问内容才会发给对应模型供应商——这跟所有 AI 工具一样。

**Q：YuCode 会不会动我 ZCode 里的文件？**
独立模式下不会碰 ZCode 任何文件。
共生模式下**共用**同一份数据（同看同写），但 YuCode 只在文件**不存在**时才写自己的默认版本，
你自己写的内容一个字不动。

**Q：我自己的 AGENTS.md 会被覆盖吗？**
不会。只在缺失时种入默认版。你写的（哪怕是从别的工具迁过来的）都原样保留。

## 渗透工作台

**Q：为什么面板上少了一个目录？**
刚建的目录（还没有报告/资产）也会出现在导航列里，计数为 0。
如果连行都没有：确认它在桌面根目录下、或已通过「导入任务目录」指定；
再看「扫描提示」徽标是否报了格式原因。

**Q：我的报告格式没被认出来？**
报告等级要能认出来，写法见 [使用教程 §三](使用教程.md)。
都不写的话会归到「未分级」——单独一档，不会丢，但统计上不区分严重性。

**Q：Excel 另存的清单能认吗？**
能。分隔符和编码自动嗅探，见 [使用教程 §三](使用教程.md)。
带表头的必须有主机列，列名写 `host` / `域名` / `资产` 都认。

**Q：任务目录能选到别的盘吗？**
能，点目录名切换，或用「浏览…」选任意位置，会自动导入并绑定。
不想绑了点「解除绑定」退回自动判定。

**Q：批量派发跑到一半断了？**
流程树支持无人值守续跑，重新进来会接着上次的进度继续。

## 模型与网络

**Q：连不上模型？**
- 检查 API Key 有没有过期
- 共生模式下确认 ZCode 那边能正常连（两者用同一份配置）
- 有些网络需要代理：设置 ▸ 网络 里配

**Q：能不能接自己的模型（Ollama / 兼容 API）？**
能，只要兼容 OpenAI 格式，在 设置 ▸ 模型供应商 里加一个自定义供应商即可。

**Q：YuCode 会去连 ZCode 官方的更新通道吗？**
**绝对不会。** 未配置自有更新源时更新功能是完全禁用的，
就是为了避免误连官方通道弹出官方安装包把 YuCode 覆盖掉。
