# YuCode 使用教程

面向普通用户：从装上到日常干活。不需要命令行，不需要配置文件。

---

## 一、安装与首次启动

1. 打开 [Releases](../../releases/latest)，下载 `YuCode-1.0.1-win-x64.exe`（约 163 MB）。
2. 双击安装，一路点「下一步」即可。安装路径可以改，默认在 `C:\Program Files\YuCode`。
3. 首次启动会让你选**运行模式**，两个卡片，选一个：

   | 模式 | 数据存在哪 | 适合谁 |
   | --- | --- | --- |
   | **独立使用** | 只在 `~/.yucode`，完全不读 ZCode 任何文件 | **新用户 / 没装 ZCode 的人选这个** |
   | **与 ZCode 共生** | 与已装的 ZCode 共用 `~/.zcode` | 已经在用 ZCode 的人——API 配置、登录态、对话历史、记忆全部互通，**不用重配 API** |

4. 点「确定并继续」，提示重启就点「重启以生效」。

> **选错了怎么办？** 设置 ▸ **数据与模式** 里随时切换，切换需要重启（按钮就在旁边）。
>
> **选了「共生」但机器上其实没装 ZCode？** 不用手动改——YuCode 检测不到会自动回退到独立模式，
> 并在设置页标明实际生效的是哪个。

5. **连接模型**：按提示登录账号（Z.ai / BigModel），或点「使用 API key」填自己的 Key。
6. **激活**：首屏「机器码注册」卡——复制机器码发给作者，换回激活码粘贴进去，点「激活」。
   详见 [激活与授权](激活与授权.md)。激活不是必须的，不激活也能连模型、也能用基础功能。

---

## 二、打开渗透测试工作台

- 侧栏面板（右侧 ▸ +）▸ **渗透工作台**。工作台与对话区可拖宽、可折叠、可并排。
- 左侧列从上到下：**资产 / 漏洞 / 仪表盘 / 流程树** 四个视图，外加全局导航列。

---

## 三、任务目录：文件丢进去就入库

这是最省事的一步——**不用手工录数据**。

1. 在「渗透工作台」里找到 **任务目录** 设置，把你放报告的根目录指进去
   （默认是桌面，可以指任意位置）。
2. 之后你往那个目录里丢文件，YuCode 自己认：

   ```
   你的目录/
   ├── 某厂商/
   │   ├── 2026-09-15/          ← 报告按「厂商/日期」分层放最容易认
   │   │   ├── 任意文件名.md
   │   │   └── 漏洞等级：高危      ← 等级写在正文里也认
   │   └── 漏洞等级：高危          ← 或者用目录名/文件名定级
   └── 资产清单.xlsx              ← Excel 另存的清单也认
   ```

3. **报告等级怎么标**（三处任选其一，优先级：目录名 > 正文 > 文件名）：

   认 `严重 / 高危 / 中危 / 低危 / 信息`，也认 `critical / P0 / high / P1` 等同义词。
   都不写 = 未分级（单独一档，不会丢）。

4. **清单是 Excel 另存的能认吗？** 能。分隔符（Tab/逗号/分号）和编码（UTF-8/GBK/UTF-16）
   自动嗅探；带表头必须有主机列（`host` / `域名` / `资产` 等写法都认）；
   FOFA 无表头导出（域名 Tab 端口 Tab 单位名）直接放。

5. **目录选择**：点目录名可以换到任意其他目录；「浏览…」按钮能选任意位置并自动导入绑定；
   「解除绑定」可以退回自动判定。

## 四、日常挖洞流程

1. **导入资产**：把 FOFA / Excel / 文本清单丢进任务目录，或直接粘贴到对话框让 Agent 处理。
2. **派发**：流程树里选一批目标，派发成一个任务，Agent 逐个跑。
3. **看进度**：仪表盘看全局分布，流程树看单次执行进度（支持无人值守续跑，中断了能接着跑）。
4. **收洞**：出了洞写成报告丢回任务目录，面板自动入库、定级、关联资产。
5. **成稿**：让 Agent 按报告规范整理，直接可提交。

## 五、常用入口

| 想做的事 | 去哪 |
| --- | --- |
| 切运行模式 / 看数据在哪 | 设置 ▸ **数据与模式** |
| 换模型 / 接自己的 API | 设置 ▸ **模型供应商** |
| 开关自动更新 | 设置 ▸ **更新** |
| 看授权状态 | 首屏「机器码注册」卡 / 设置 ▸ 关于 |
| 加技能 / 扩展工具 | 技能目录（激活后内置技能自动启用） |
| 改 Agent 行为 | 规则文件（工作台内的规则页） |
