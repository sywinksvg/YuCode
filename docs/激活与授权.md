# 激活与授权

YuCode 采用**机器码绑定授权**：一份激活码对应一台电脑。

---

## 激活流程（三步）

### 第 1 步：拿到你的机器码

安装后首次启动，首屏（连接账号页）**上方**有一张「**机器码注册**」卡，
里面那串 32 位字符就是你的机器码。点旁边的「复制」按钮。

设置 ▸ 关于 里也能找到同一串。

### 第 2 步：换激活码

把机器码发给作者（**1342067963@qq.com**），你会收到一串这样的东西：

```
YUC1.eyJsaWNlbnNlZSI6IuiHqua1i-WuouaItyIsIm1hY2hpbmVJZCI6Ii4uLiJ9.6cdszvd_4R9iKscpQXu3j6sOQIQ4VbTKE7gbA0DUTZXy7Hsq0nVB87dLjHJeLjPJAbI01IPd8InndGXyc6hjAw
```

一整串复制好，别在中间换行。（`YUC1.` 开头，中间两个 `.` 分隔）

### 第 3 步：粘贴激活

回到那张注册卡，把激活码粘进输入框，点「**激活**」。

- **立即生效，不需要重启**
- 成功后卡片会收成一行：`已激活 · 授权给 xxx，有效期至 xxxx`
- 激活后**内置技能资产会自动解密启用**

---

## 不激活会怎样

**不激活也能正常用。** YuCode 的基础功能——连模型、多智能体协作、对话、记忆、
渗透工作台——都不需要激活。

激活解锁的是：

- 内置技能资产（渗透测试方法论、检查清单、知识库卡片）
- 后续版本的商业功能

换句话说：**激活码买的是"进阶内容"，不是"能不能用"。**

## 常见激活问题

**Q：提示"激活码换机器被拒"？**
授权是绑机器的。如果你在 A 电脑申请的码拿到 B 电脑用，会被拒。
换机器 / 重装系统后机器码会变，需要重新申请一份。

**Q：提示"授权已过期"？**
授权到期了。联系作者续期，会给你新码。

**Q：提示"签名无效"？**
码被截断了（复制时少字符），或者中间混进了空格/换行。
重新复制完整的一整段。

**Q：粘贴报"既不是激活码，也不是有效的授权文件"？**
检查是不是少了开头。必须以 `YUC1.` 开头、以 `.` 分成三段。

**Q：找不到「机器码注册」这张卡？**
说明你用的是不含授权门槛的版本（开源构建），那张卡不会渲染，功能也不打折。
从 [Releases](../../releases/latest) 下载的正式发行包才有。

**Q：授权文件在哪？**
`~/.ycode/license.json`（即 `C:\Users\你的用户名\.ycode\license.json`）。
这个文件和 ZCode 的目录无关，ZCode 读不到你的授权。

## 给作者（内部说明，不用发给客户）

签发一条授权：

```bash
pnpm license:issue -- --machine <客户机器码> --licensee "客户名" --days 365
```

命令会**同时**产出两样东西：

| 文件 | 用途 |
| --- | --- |
| `license.json` | JSON 形态，客户选文件导入时用 |
| `license.json.code.txt` | **单行激活码**，微信/QQ 直接发——优先用这个 |

永久授权加 `--perpetual`；不绑机器的 7 天试用加 `--trial`。
签发私钥在 `~/.ycode/license-keys/issuer-private.pem`，**绝不能外传**。

### 授权是怎么防伪造的

- 授权内容由**私钥**签名（Ed25519），应用里只内置**公钥**做验签
- 没有私钥就造不出有效签名——这是数学上不可伪造的，不是靠代码保密
- 验签三件事一起过：签名有效 + 没过期 + 机器码匹配
- 篡改码里任何一个字符，签名立刻失效

### 已知边界（如实说明）

- 逆向者能看到验签逻辑和公钥。防线是**签名不可伪造**，不是"别人看不懂代码"。
- 纯离线验签理论上可以被 patch 绕过。YuCode 用多层加载 + 每次更新重新编译抬高门槛，
  但**不能承诺绝对防破解**。
- 要更高强度需要在线心跳校验，那需要一台服务器。当前离线模型覆盖
  「授权可控、伪造不了」这个需求。

如果你的使用场景需要更强的一层（比如按月校验、按设备数计费、远程吊销），
那就不是激活码能解决的，得上服务端——到时候再说。
